# wikitranslate（Wikihonyaku）

英語版と日本語版の Wikipedia を比べ、日本語版がない・情報量が少ない記事（補完候補）を探すツールです。

## 公開ページ

https://arbeit2025.github.io/wikitranslate/

ブラウザだけで動作する単一 HTML のツールで、インストールは不要です。

## 関連ツール

- [wikitransgeo](https://github.com/Arbeit2025/wikitransgeo) — 地理分野に絞った試作版
- [wikisourcesearch](https://github.com/Arbeit2025/wikisourcesearch) — 参考文献・一次資料探し
- [wikiImagesearch](https://github.com/Arbeit2025/wikiImagesearch) — Wikimedia Commons の画像探し
